========================================
OpsMate Docker Deployment Report
========================================

Project Name:
Containerizing and Deploying OpsMate Service Using Docker and AWS

----------------------------------------
1. Project Overview
----------------------------------------

OpsMate is a Node.js application containerized using Docker.

The project demonstrates:
- Docker image creation
- Docker container management
- Docker networking
- Docker Compose
- PostgreSQL database integration
- AWS ECR
- AWS ECS/Fargate deployment

----------------------------------------
2. Docker Environment
----------------------------------------

Operating System:
Ubuntu 26.04 LTS

Docker Version:
Docker 29.1.3

Docker Compose Version:
Docker Compose v5.5.0

AWS Region:
ap-south-1

----------------------------------------
3. Dockerfile
----------------------------------------

The Dockerfile uses Node.js as the base image.

Main Dockerfile instructions used:
- FROM
- WORKDIR
- COPY
- RUN
- EXPOSE
- CMD

The application dependencies are installed using npm install.

----------------------------------------
4. Docker Image
----------------------------------------

Application image:

opsmate:1.0

The image was created using:

docker build -t opsmate:1.0 .

----------------------------------------
5. Docker Container
----------------------------------------

Container name:

The container was started using:

docker run -d \

8. Persistent Storage
----------------------------------------

PostgreSQL data is stored using a Docker named volume:

postgres-data

This allows database data to persist when the PostgreSQL
container is recreated.

----------------------------------------
10. Docker Scripts
----------------------------------------

The project contains the following scripts:

scripts/install-docker.sh
scripts/build-image.sh
scripts/run-container.sh
scripts/cleanup.sh

Purpose:

install-docker.sh
- Installs Docker
- Starts Docker service
- Enables Docker at boot

build-image.sh
- Builds the OpsMate Docker image

run-container.sh
- Removes an old container
- Starts the OpsMate container
- Maps port 8080
- Tests the health endpoint

cleanup.sh
- Stops the OpsMate container
- Removes the container
